# Player feedback retained for the next balancing pass

v0.6.1 was played for more than an hour across Creator Network, Live Arena, Market Watch and Thread Frontier. Player reported novelty and repeat interest alongside high cognitive load at peak difficulty.

## Feedback — defer any v0.6.1 changes

1. **Live Arena queue selection:** selecting a secondary chat is rarely useful when the main lane demands continuous focus. Proposal to test later: fixed primary actionable lane with optional inspect-only side items, not manual chat focus selection.
2. **Freeze / Focus power-ups:** seldom used despite potential value because the player is concentrating on reading and making one of three moderation decisions. Proposal to test later: automatic tutorial trigger, prominent one-tap emergency affordance near action buttons, or a passive auto-trigger upgrade.
3. **Negative spiral after missing a few posts:** missed actions may cause cascading queue pressure, frustration and button-mashing. Proposal to test later: smoother recovery grace, post-error tempo ramp rather than instant repeated penalties, clearer feedback on one mistake versus several.
4. **Disputed content cues:** keyword heuristics can be misleading; players sometimes misread an unverified claim as fraud. This is a potentially useful distinction when learnable, but the correction explanation may require a bit more feedback.
5. **Intermittent Live Arena queue lockout:** player saw a report resembling "queue overflow" followed by decisions no longer being accepted and an automatic loss. Could not reproduce after ten minutes. First-pass source inspection found congestion/recovery logic, but no proven stuck state. **No change made.** Retain request for device, level, upgrades, time in round and video/screenshot if it recurs.
