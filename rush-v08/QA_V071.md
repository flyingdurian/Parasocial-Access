## Known limitations / follow-up

1. Different Vercel preview hostnames cannot access each other's localStorage; use explicit JSON save transfer. This build does **not** magically recover progress from an old origin.
2. Mobile Safari/iPhone physical-device input, clipboard permissions and localStorage persistence require owner verification.
3. Import overwrite is guarded by explicit browser confirmation; a pre-import backup is stored in localStorage but a one-click “restore previous” UI is not yet exposed.
4. v0.7 IRL gameplay remains a rejected vertical prototype. The visual-first v0.8 design is proposed separately and not coded here.
5. New Destiny/DGG lore research has not been inserted into this build's content generator.
